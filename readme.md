# Travel Agency Landing Page

A responsive and modern landing page for a travel agency, built to showcase destinations, packages, and services.

## Features

- Attractive hero section with call-to-action
- Featured destinations and packages
- Responsive design for all devices
- Contact form for inquiries

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/JayapriyaSiakumar/Trabook.git
   ```
2. Open `index.html` in your browser.

## Folder Structure

```
/Trabook
  ├── index.html
  ├── style.css
  └── Assets/
```

## Customization

- Update images in the `images/` folder.
- Edit content in `index.html` as needed.
